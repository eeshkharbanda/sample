How is this calculated?

Bag width = Breadth + Height + margin (the bag has to wrap around the product's cross-section).
Bag body length = Length + margin.
Total length = body length + 2 in flap (5.08 cm) for the adhesive strip.
With "round up" on, each is rounded up to the next whole inch.
